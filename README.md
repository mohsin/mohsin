## About Me

I design and ship complete products end-to-end — from AI-driven web apps and native iOS/Android experiences to scalable AWS/GCP architectures and CI/CD pipelines. My work spans 40+ client projects across India, Australia, Singapore, and the UK, with apps reaching 50K+ users and open-source packages clocking 6,000+ installs.

Currently focused on **AI agent development** (LangGraph, Claude, Gemini), **cross-platform mobile** (Kotlin/Swift, KMM), and **cloud-native infrastructure**.

🌍 **Location**: Bangalore, India — working remotely worldwide

## What I Do

- Build web applications with React, Vue, Next.js, Nuxt.js, Laravel, and OctoberCMS
- Develop AI agents and conversational pipelines using LangGraph, Claude, and Gemini
- Build native iOS (Swift) and Android (Kotlin) apps and cross-platform solutions with KMM
- Integrate third-party APIs and payment gateways (Razorpay, ZohoCRM, Google Calendar, HubSpot, and more)

- Orchestrate containerized workloads with Docker and Kubernetes
- Build and publish open-source plugins and packages
- Speak at developer conferences and run technical workshops
